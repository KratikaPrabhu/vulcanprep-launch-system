# VulcanPrep Website Launch System (Phase 1)

This is an independent launch system to control a real-time website launch ceremony using a QR code, a mobile device, and a large LED screen.

## Technologies Used
- Frontend: React + Vite + React Router + Socket.io-client
- Backend: Node.js + Express + Socket.io

## Prerequisites
- Node.js (v18+ recommended)
- npm or yarn
